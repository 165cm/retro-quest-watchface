# 画面のルール（UI_RULES）

<!-- 画面がないリポジトリでは、このファイルを消してよい（AGENTS.md の目次からも消す） -->

## 1. 文字は最小限

- 伝えるべきことは伝え、くり返しと毎回の説明は削る
- 毎回読まなくていい説明は ⓘ（押すと出る吹き出し）に入れる
- 意味が伝わるところは、絵文字＋短い言葉
- 押した結果は、押した場所の近くで返す。取り消せる操作には「↩ 元に戻す」

## 2. スマホ1画面の密度

- スマホが基本（縦 390×844 で確認）。横持ち・パソコンでも崩れないこと
- 主な操作のボタンは押せる大きさ（高さ44px以上）
- 1画面に主な目的は1つ

※ このリポジトリの主な画面は**時計の文字盤**。上の「スマホ縦 390×844」は、Zepp アプリの設定画面（各文字盤の `setting/index.js`）に当てはめる。文字盤は下の3〜4で確認する。

## 3. 全部の文字盤に共通すること

- 時刻の読みやすさが最優先。ほかの部品で時刻を小さくしたり、重ねたりしない
- 状態は色だけで伝えない（例：電池は%の数字も出す）
- 座標・大きさは各文字盤の `watchface/layout.js`、色・文字の大きさは `watchface/theme.js` だけにまとめる
- 背景の上の文字には、読みやすくするための下敷き（半透明の帯など）を敷く
- AOD（画面オフ時）は黒い背景に、時刻と最小限の情報だけ。光る部分を少なく保つ（画面の10%未満のつもり）。焼き付きを防ぐため
- 画面の端から12pxは余白にする

## 4. 文字盤ごとの色・形

### Pixel Wayfarer（`faces/pixel-wayfarer/`・390×450）

色は `watchface/theme.js` の `COLORS` だけを使う。

| 用途 | 名前 | 色 |
|---|---|---|
| 地の色 | `BACKGROUND_NAVY` | `#031426` |
| ウィンドウの中 | `PANEL_NAVY` | `#061B31` |
| 文字・枠 | `TEXT_PRIMARY`／`PANEL_EDGE` | `#F4F3E8` |
| 控えめな文字 | `TEXT_MUTED` | `#A9B0B8` |
| 枠の飾り（金） | `PANEL_ACCENT_GOLD` | `#C9A85C` |
| 最低気温 | `LOW_BLUE` | `#69A7E8` |
| 最高気温 | `HIGH_ORANGE` | `#E98A4A` |
| HP 多い／中／少ない | `HP_GREEN`／`HP_YELLOW`／`HP_RED` | `#62B84A`／`#E1B84A`／`#D9534F` |
| HP 空 | `HP_EMPTY` | `#183047` |
| AOD の文字 | `AOD_TEXT` | `#B8B8B8` |

- 形：昔のRPGのウィンドウ風。角は丸めない（枠は `radius: 0`）。白い2pxの枠＋四すみに金の小さな四角。ひとことの枠は内側に金の1px線
- 数字：オリジナルの 5×7 ドットの字形を画像にしたもの（時刻・気温）。英字は時計のシステムフォント
- 英語は大文字（例：`7/24 FRI`、`TACTIC / SAFETY FIRST`）
- 並び（上から）：気温（左に最低 L・青、真ん中に現在を大きく、右に最高 H・オレンジ）→ ひとことのウィンドウ → 時刻（12時間制なら右に AM/PM）→ 日付（`M/D 曜日`）→ HP ゲージ（10マス＋%）
- AOD：時刻・日付・HP（暗い灰色）だけ。天気・気温・ひとこと・飾りは出さない

### SUPER ARBEITER（`faces/super-arbeiter/`・390×450）

色は `watchface/theme.js` と `tools/generate-assets.mjs` の `C` をそろえる。

| 用途 | 名前 | 色 |
|---|---|---|
| 地 | `YELLOW` | `#FFE033` |
| 強調（電池の残りの数字と塗り） | `RED` | `#E10606` |
| 時刻・日付・曜日・歩数 | `BLACK` | `#000000` |
| 吹き出しの中 | `CREAM` | `#FFF5D6` |
| AOD の文字 | `AOD_TEXT` | `#8C8676`（暗いクリーム） |

- 作り方：ユーザーから受け取った最終採用案（`docs/reference-approved.png`）の背景を1枚の絵として使い、数字・曜日・セリフの札・電池の塗りだけを時計で重ねる
- 並び（上から）：通知アイコンのための赤い余白と暖簾「スーパー／アルバイター」（左右に提灯）→ 左に日付と曜日・右に時刻（いちばん大きく）→ 左に丼・右に吹き出しのセリフ → 下の段（くつ 歩数｜電池 残り）
- 下の段にはラベル（STEPS・HP）や単位を出さない。アイコンと数字と区切りだけ。BREAK は出さない
- 曜日は日本語で `(日)`〜`(土)`
- 日付と曜日は、カレンダーのアイコンの中央（x=40.5）にそろえる。日付の数字は字ごとの幅の画像（`DIGITS.date.widths`）にし、字の左右の余白をそろえる。全月日・全曜日で 0.5px 以内（テストで確かめている）
- 通知アイコン：画面の上のまん中（`layout.js` の `NOTIFICATION`、y 0〜46）に文字を置かない。通知アイコンは背景に描き込まない（確認図 `docs/check-notification.png` は別の重ね絵）
- セリフ：`watchface/quotes.js` の7枚を1枚だけ出し、画面が点くたびに順番に次の札へ替える（省電力のため、画面が消えている間は替えない）。7枚を同時に描かない。札は吹き出しの黒い枠を隠さない（下地は透明。テストで確かめている）。縦横を別の倍率で伸ばさない。画面に名前や出典を出さない
- 動かない物（暖簾・提灯・カレンダー・丼・吹き出し・雷紋・くつ・区切り・電池の枠）は、背景の1枚の絵にまとめる。別の部品で二重に描かない
- 時刻の数字：`tools/brush-digits.mjs` で1字ずつ作った筆の字形（塗りつぶし）。太さと傾きは `watchface/theme.js` の `DIGIT_STYLE`。時刻は黒でいちばん太く、かすれ入り。AOD は細く、かすれなし
- 小さい数字（日付・歩数・電池）と曜日：フォントの字形（`source/glyphs/`、ちかフォント＋補助の書体）。数字は全部同じ倍率で、画像の中央に置く
- 数字の穴（0・4・6・8・9）は原寸でもつぶれないこと。数字の画像はふちで切らないこと。となりの数字とくっつかないこと。日付が時刻にくっつかないこと。どれもテストで確かめている（全時刻・全月日・電池 100・歩数6桁）
- 電池は色だけでなく数字でも出す
- 四隅：Bip 6 は四隅が大きく丸い（半径およそ105px）。数字と文字（背景の絵の中の文字も `layout.js` の `BAKED_TEXT` で）は四隅と端12pxの内側に収める（テストで確かめている）
- AOD：黒い背景に、時刻・日付と曜日・HP（暗いクリーム）だけ。暖簾・提灯・丼・セリフ・くつ・歩数は出さない
- キャラクター・公式ロゴは使わない（`docs/PRODUCT.md` の「権利の約束」）

### KAMONT（`faces/kamon/`・390×450）

元のデザイン（ユーザーのドラマ風の時計）の配置・色・大きさをそのまま使い、問題のあった所だけを置き換える（ユーザーの指示）。座標と色は、元のデザインのプレビューから測った値。色は `watchface/theme.js` の `COLORS` だけを使う（`tools/generate-assets.mjs` もここから読む）。

| 用途 | 名前 | 色 |
|---|---|---|
| 地 | `BLACK` | `#000000` |
| 紋（墨色） | `SUMI` | `#222222` |
| 時刻・下の段の数字・ハート・電池の塗り | `RED` | `#FF001F` |
| 題字の左右の線・下の段の区切り | `RULE` | `#80000E` |
| 題字・日付・アイコン | `CREAM` | `#F2E6D8` |
| レアのタイトル／レアの紋 | `GOLD`／`GOLD_DIM` | `#C8A45A`／`#6E5524` |
| AOD の時刻／日付 | `AOD_TIME`／`AOD_TEXT` | `#8A0012`／`#6E665E` |

- 並び（上から）：タイトル（紋ごとの英単語、8文字まで）と左右の赤い線（y 52〜62）→ 太い墨色の輪と七宝の紋 → 大きな赤い時刻（数字は y 185〜261）→ 日付 `WED 30 SEP` → 下の段（気温｜歩数｜心拍｜電池、区切りは x 99・216・294）
- 時刻の数字：Liberation Sans Bold。1字 52×76、70px おき。「:」は幅5pxの縦長の四角2つ（元のデザインと同じ）。テストで位置を確かめている
- 紋：太い輪（外の半径152・太さ28。背景）と、その中の紋（9種類。画面が点くたびにランダムに1つ。直前と同じものは出さない）。墨色で時刻の後ろに控えめに。レアは暗い金。元の六角形のマーク（亀甲）に近づけない
- 紋とタイトルは1枚ずつだけ置き、画像を入れ替える（全部を同時に描かない）。画面が消えている間・分ごとには替えない
- 下の段：アイコンは温度計・足あと（生成り）、ハート（赤）、電池の枠（生成り。中を残りに合わせて赤く塗る）。単位の文字は出さない（気温の「°」だけ）。データが無い時は「--」
- 大きい値（気温 `-12°`・歩数 `99999`・心拍 `199`・電池 `100`）が区切りの間に入ること。テストで確かめている
- 通知アイコン：上のまん中（`layout.js` の `NOTIFICATION`、y 0〜48）には、背景の絵も含めて何も描かない（テストで確かめている）
- 四隅：元のデザインのプレビューの画面の形（`layout.js` の `CORNER_INSET`）から、さらに4px内側に収める（テストで確かめている）。ほかの文字盤の「半径105px」より端に近いので、実機で確かめる
- AOD：黒い地に、暗い赤の時刻と暗い色の日付だけ。紋・題字・下の段は出さない。光る所は画面の10%未満（テストで確かめている）
