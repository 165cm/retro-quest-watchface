# 画面のルール（UI_RULES）

## 1. 文字は最小限

- 伝えるべきことは伝え、くり返しと毎回の説明は削る
- 毎回読まなくていい説明は ⓘ（押すと出る吹き出し）に入れる
- 意味が伝わるところは、絵文字＋短い言葉
- 押した結果は、押した場所の近くで返す。取り消せる操作には「↩ 元に戻す」

## 2. スマホ1画面の密度

- スマホが基本（縦 390×844 で確認）。横持ち・パソコンでも崩れないこと
- 主な操作のボタンは押せる大きさ（高さ44px以上）
- 1画面に主な目的は1つ

※ このリポジトリの主な画面は**時計の文字盤**。上の「スマホ縦 390×844」は、Zepp アプリの設定画面（各文字盤の `setting/index.js`）に当てはめる。文字盤は下の3〜4で確認する。

## 3. 全部の文字盤に共通すること

- 時刻の読みやすさが最優先。ほかの部品で時刻を小さくしたり、重ねたりしない
- 状態は色だけで伝えない（例：電池は%の数字も出す）
- 座標・大きさは各文字盤の `watchface/layout.js`、色・文字の大きさは `watchface/theme.js` だけにまとめる
- 背景の上の文字には、読みやすくするための下敷き（半透明の帯など）を敷く
- AOD（画面オフ時）は黒い背景に、時刻と最小限の情報だけ。光る部分を少なく保つ（画面の10%未満のつもり）。焼き付きを防ぐため
- 画面の端から12pxは余白にする

## 4. 文字盤ごとの色・形

### Pixel Wayfarer（`faces/pixel-wayfarer/`・390×450）

色は `watchface/theme.js` の `COLORS` だけを使う。

| 用途 | 名前 | 色 |
|---|---|---|
| 地の色 | `BACKGROUND_NAVY` | `#031426` |
| ウィンドウの中 | `PANEL_NAVY` | `#061B31` |
| 文字・枠 | `TEXT_PRIMARY`／`PANEL_EDGE` | `#F4F3E8` |
| 控えめな文字 | `TEXT_MUTED` | `#A9B0B8` |
| 枠の飾り（金） | `PANEL_ACCENT_GOLD` | `#C9A85C` |
| 最低気温 | `LOW_BLUE` | `#69A7E8` |
| 最高気温 | `HIGH_ORANGE` | `#E98A4A` |
| HP 多い／中／少ない | `HP_GREEN`／`HP_YELLOW`／`HP_RED` | `#62B84A`／`#E1B84A`／`#D9534F` |
| HP 空 | `HP_EMPTY` | `#183047` |
| AOD の文字 | `AOD_TEXT` | `#B8B8B8` |

- 形：昔のRPGのウィンドウ風。角は丸めない（枠は `radius: 0`）。白い2pxの枠＋四すみに金の小さな四角。ひとことの枠は内側に金の1px線
- 数字：オリジナルの 5×7 ドットの字形を画像にしたもの（時刻・気温）。英字は時計のシステムフォント
- 英語は大文字（例：`7/24 FRI`、`TACTIC / SAFETY FIRST`）
- 並び（上から）：気温（左に最低 L・青、真ん中に現在を大きく、右に最高 H・オレンジ）→ ひとことのウィンドウ → 時刻（12時間制なら右に AM/PM）→ 日付（`M/D 曜日`）→ HP ゲージ（10マス＋%）
- AOD：時刻・日付・HP（暗い灰色）だけ。天気・気温・ひとこと・飾りは出さない
