# 何を作っているか（PRODUCT）

## ひとことで

Zepp OS のスマートウォッチ（いまは Amazfit Bip 6）用の、オリジナルの文字盤を作るリポジトリ。
1つのリポジトリで複数の文字盤を作り、それぞれ別の文字盤として Zepp のストアに出す。

## 全部の文字盤に共通すること

- 時刻がいちばん読みやすいことを優先する
- 絵・数字はプログラムで描いたオリジナル。既存ゲームの絵・ロゴ・フォント、生成AIの画像は使わない
- 電池にやさしくする：分ごと・電池の変化・文字盤に戻った時だけ更新し、秒の表示やアニメーションは入れない
- 天気・電池・時刻の数字など、使い回せる部品は `shared/` にまとめる

## 文字盤

### Pixel Wayfarer Face（`faces/pixel-wayfarer/`）

昔のRPGゲーム風のドット絵の文字盤。天気・気温・電池残りを、ゲームの画面のように楽しく見せる。

中心の使い方：

1. 腕を上げて時刻を見る（大きなドット数字）
2. ついでに天気（背景の絵）・最低／現在／最高気温・電池（HPゲージ）を見る
3. 画面が消えている時（AOD）は、黒い背景に時刻・日付・HPだけを暗く出す
4. スマホの Zepp アプリの設定で、下のひとこと（例：`TACTIC / SAFETY FIRST`）を6種類から選ぶ

強み：

- 天気で背景が10種類に変わる（晴れ・くもり・雨・雷・雪・霧・夜など）。昼と夜は日の出・日の入りで切り替える
- 電池を「HP」として10マスのゲージで表示。残りで緑・黄・赤に変わり、数字（%）も出す

### Yuge Ramen Face（ゆげラーメン・`faces/yuge-ramen/`）

ラーメン屋のバイトで使うための、パステルでゆるい手描き風の文字盤。背景はラーメン屋の店内（のれん・赤ちょうちん・窓・木のカウンターと湯気の立つラーメン）で、真ん中の木札がシフトの残り時間を教えてくれる。キャラクターは出さない。

中心の使い方：

1. スマホの Zepp アプリで、その日のシフトの時刻（はじまり・おわり）を入れる
2. 勤務中に腕を上げて、時刻と木札の「おわりまで あと 2:15」を見る
3. ついでに歩数・電池・天気（窓の外の空）を見る

強み：

- シフトの前・中・あとで、木札の文が変わる
- 画面オフ（AOD）でも、シフトの残り時間が見える

権利の約束：既存作品（例：ちいかわ）のキャラクター・名前・ロゴ・画像は使わない。キャラクターは描かず、お店の名前やロゴのような文字も描かない。参考にするのは、パステルの色やゆるい線など「画風の雰囲気」だけ。

## やらないこと（追いかけない）

- 秒の表示・アニメーション（電池がもつことを優先）
- 既存ゲームに似せた絵・名前（権利のため）。仮の名前「Retro Quest Face」は、似た名前の商標出願が見つかったので使わない
- 既存作品のキャラクターを使った文字盤・似せたキャラクター（作者の権利のため）
- 1つの文字盤の中で、別の文字盤に切り替える機能（文字盤はそれぞれ別のアプリとして出す）
- Pixel Wayfarer でいまは入れていないが、将来の候補：ひとことの自由入力、気温ラベルの切り替え、細いHPバー
