# 何を作っているか（PRODUCT）

## ひとことで

Amazfit Bip 6（スマートウォッチ）用の、昔のRPGゲーム風のドット絵の文字盤「Pixel Wayfarer Face」。
時刻がいちばん読みやすいことを優先しながら、天気・気温・電池残りを、ゲームの画面のように楽しく見せる。

## 中心の使い方

1. 腕を上げて時刻を見る（大きなドット数字）
2. ついでに天気（背景の絵）・最低／現在／最高気温・電池（HPゲージ）を見る
3. 画面が消えている時（AOD）は、黒い背景に時刻・日付・HPだけを暗く出す
4. スマホの Zepp アプリの設定で、下のひとこと（例：`TACTIC / SAFETY FIRST`）を6種類から選ぶ

## 強み

- 絵・数字はすべてプログラムで描いたオリジナル（`tools/generate-assets.mjs`）。既存ゲームの絵・ロゴ・フォント、生成AIの画像は使っていない
- 天気で背景が10種類に変わる（晴れ・くもり・雨・雷・雪・霧・夜など）。昼と夜は日の出・日の入りで切り替える
- 電池を「HP」として10マスのゲージで表示。残りで緑・黄・赤に変わり、数字（%）も出す
- 電池にやさしい：分ごと・電池の変化・文字盤に戻った時だけ更新し、秒の表示やアニメーションはない

## やらないこと（追いかけない）

- Bip 6 以外の端末への対応（画面の大きさ 390×450 に合わせて作っている）
- 秒の表示・アニメーション（電池がもつことを優先）
- 既存ゲームに似せた絵・名前（権利のため）。仮の名前「Retro Quest Face」は、似た名前の商標出願が見つかったので使わない
- いまは入れていないが、将来の候補：ひとことの自由入力、気温ラベルの切り替え、細いHPバー（README「設定項目」）
