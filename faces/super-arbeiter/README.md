# SUPER ARBEITER

Amazfit Bip 6 用の、ラーメン屋で働くスーパーアルバイターのための「業務ウォッチ」風の文字盤です。黄色い地に赤と黒を効かせ、暖簾・提灯・丼と、日替わりのセリフの吹き出しで店の空気を出しています。キャラクターは出しません。**自分用で、ストアには出しません。**

|---|---|---|
| ![](docs/preview-390x450.png) | ![](docs/preview-low-390x450.png) | ![](docs/preview-aod-390x450.png) |

セリフ7枚のプレビュー：`docs/preview-quote-1.png`〜`7.png`。通知アイコンとの重なりの確認図：`docs/check-notification.png`（緑の点線が通知アイコンの場所。確認用の重ね絵で、時計の背景には入っていません）。

## 表示するもの（上から）

- 上：通知アイコンのための赤い余白と暖簾「SUPER ARBEITER」、左右に「営業中」「よし!」の提灯。上のまん中（y 0〜48 あたり）には文字を置かない
- 真ん中：時刻（いちばん大きい筆の数字。システムの12/24時間設定に合わせる）。左に HP（電池の残り。赤い数字）、右に日付（`9/30`）と曜日（`WED`）
- その下：左に丼、右に吹き出しのセリフ（日替わり、7枚）
- 下の段：左に STEPS（歩数）、右に BREAK（休憩の時刻）
- AOD：黒い背景に、時刻・日付・HP だけ（暗いクリーム色）

秒・アニメーション・タップ操作はありません。更新は分ごと（HP と歩数は時計のデータが変わった時）です。

## セリフの切り替え（日替わり）

- セリフは `watchface/quotes.js` の `QUOTES` の7枚。札の画像を1枚だけ置き、その日の札に差し替えます（7枚を同時に描かない）
- どの札か：時計の日付（年・月・日）から 1970/1/1 からの通算日を出し、7 で割った余り（0 なら1枚目）
- 差し替えるのは、分ごとの更新と、画面が戻った時（`resume_call`）。同じ日のうちは何度見ても同じ札で、日付が変わると次の札になり、7日で一回りします
- 並び順を変えると日ごとの札が変わるので、足す時は末尾に足します

## BREAK の時刻

赤い BREAK の箱には、スマホの Zepp アプリで入れた休憩の時刻を出します（最初は `15:00`）。

1. Zepp アプリで、この文字盤の設定を開く
2. 「休憩の時刻」に `14:58` のように入れる

時計の側では何も操作しません。休憩のタイマー（BREAK!）や、麺ゆでのタイマー（BOIL!）を作る時は、文字盤とは別の Mini App として作る予定です。

## 使い方（リポジトリの一番上で）

```sh
npm install
npm run assets  -- super-arbeiter   # 絵とプレビューを作り直す（source/ が必要）
npm run check                       # テスト
npm run build   -- super-arbeiter   # faces/super-arbeiter/dist/ に .zab を作る
npm run preview -- super-arbeiter   # 実機に入れるための QR を出す
```

実機に入れる手順は [Pixel Wayfarer の README](../pixel-wayfarer/README.md) の「実機インストール」と同じです。

## 構成（`faces/super-arbeiter/` の中）

```text
app.json                   Bip 6、appId、3つの部分の場所
watchface/index.js         通常表示、分ごとの更新、BREAK の時刻の受け取り
watchface/layout.js        座標・大きさ（四隅の丸みと端12pxを避ける）
watchface/theme.js         色・文字の大きさ
watchface/quotes.js        セリフ7枚の並びと、日替わりの札の選び方
watchface/aod.js           AOD の表示
setting/index.js           Zepp アプリの設定画面（休憩の時刻）
setting/keys.js            設定の保存キーと読み取り
app-side/index.js          設定を時計に送る Side Service
tools/prepare-source.mjs   受け取った素材を整えて source/ に保存する（1回だけ）
tools/brush-digits.mjs     筆の数字 0〜9 と「:」の字形（1字ずつ、筆の通る点と太さで決めてある）
tools/generate-assets.mjs  source/ と筆の数字から、時計の画像とプレビューを作る
source/                    整えた素材（背景は時計の大きさの2倍、セリフの札は吹き出しの2倍）
assets/bip-6/images/       時計に入る画像
docs/                      README 用プレビュー
```

## 素材と権利

- 背景（暖簾・提灯・丼・ラベル・アイコン・吹き出し）とセリフの札7枚は、ユーザーから受け取った改修用の素材のパッケージ（`super-arbeiter-redesign-pack.zip`、2026-09-30）に入っていた、この文字盤のために生成された絵です。
- `tools/prepare-source.mjs` で次のように整えて `source/` に入れています。
  - 背景：780×900 に縮小。吹き出しの内側を平らなクリーム色にし、右下の丸い角にかかっていた BREAK の赤い箱を、まわりの黄色い地の模様で消す（箱は `generate-assets.mjs` で内側に描き直す）
  - セリフの札：文字のまわりの余白を切り落とし、下地をクリーム色にそろえて縮小
- 元の素材（合計11MBほど）はリポジトリに入れていません。作り直す時は、次のコマンドを実行します。

```sh
node faces/super-arbeiter/tools/prepare-source.mjs <素材のフォルダ>
```

- 数字 0〜9 と「:」は、`tools/brush-digits.mjs` で1字ずつ作った独自の筆の字形です。既存の書体やフォントは使っていません。
- 曜日の英字・BREAK の赤い箱は、`tools/generate-assets.mjs` でコードから描いています。
- `docs/reference-600.png` は、前の構図のときの参考画像です（時計には入りません）。
- 公式キャラクター・公式ロゴ・公式フォントは使っていません。画面には、キャラクターの名前やセリフの出典を出しません。セリフを使うので、自分の時計で使うだけにし、ストアには出しません。
- 画面の日本語（AOD の日付と HP）は、時計のシステムフォントで出します。

## 既知の制限

- 実機 Bip 6・Simulator では、まだ確認していません。ビルドまで確認済みです。特に、通知アイコンが暖簾の上の赤い余白に収まるか、AOD との切り替え、HP・歩数の更新、日付が変わった時のセリフの切り替えは、実機で見る必要があります。
- 通知アイコンの場所（`layout.js` の `NOTIFICATION`）は、素材の見本から測った値です。
- `appId`（`20260930`）は仮の値です。自分の時計で使うだけならこのままでも動く見込みです。
- 12時間制にしている時、AM/PM は表示しません。
- BREAK の赤い箱のふちは、画面の端12pxの余白に少しかかります（飾りなので、そのままにしています。数字は余白の内側です）。
