# SUPER ARBEITER

Amazfit Bip 6 用の、ラーメン屋で働くスーパーアルバイターのための「業務ウォッチ」風の文字盤です。黄色い地に赤と黒を効かせ、暖簾「スーパー／アルバイター」・提灯・丼と、セリフの吹き出しで店の空気を出しています。キャラクターは出しません。**自分用で、ストアには出しません。**

## 表示するもの（上から）

- 上：通知アイコンのための赤い余白と、暖簾「スーパー／アルバイター」（クリーム色の2段）。左右に「営業中」「よし!」の提灯。上のまん中（y 0〜46）には文字を置かない
- 時刻：いちばん大きく、画面の左右のまん中に。太い丸ゴシックの数字（システムの12/24時間設定に合わせる）
- その下：左に丼、右に吹き出しのセリフ（7枚。画面が点くたびに替わる）
- 下の段：カレンダーのアイコンと日付（`9/30`）｜くつのアイコンと歩数｜電池のアイコン（残りに合わせて赤く塗る）と電池の残り（赤い数字）。数字はアイコンのすぐ右。ラベルや単位は出さない
- AOD：黒い背景に、時刻・日付と曜日（`9/30(水)`）・HP だけ（暗いクリーム色）。曜日は AOD だけに出す

秒・アニメーション・タップ操作・スマホの設定はありません。更新は分ごと（歩数と電池は時計のデータが変わった時）です。

## セリフの切り替え（画面が点くたび）

- セリフは `watchface/quotes.js` の `QUOTES` の7枚。札の画像を1枚だけ置き、差し替えます（7枚を同時に描かない）
- 腕を上げるなどで画面が点くたび（`resume_call`）に、1→2→…→7→1 と順番に次の札へ替わります。順番なので、同じセリフが続きません
- 省電力のため、替えるのは画面が点いた瞬間の1回だけ。画面が消えている間や分ごとの更新では替えません。何枚目かは時計の記憶に置くだけで、保存領域には書き込みません（文字盤を入れ直すと1枚目から）
- 足す時は末尾に足します

## 使い方（リポジトリの一番上で）

```sh
npm install
npm run assets  -- super-arbeiter   # 絵とプレビューを作り直す（source/ が必要）
npm run check                       # テスト
npm run build   -- super-arbeiter   # faces/super-arbeiter/dist/ に .zab を作る
npm run preview -- super-arbeiter   # 実機に入れるための QR を出す
```

実機に入れる手順は [Pixel Wayfarer の README](../pixel-wayfarer/README.md) の「実機インストール」と同じです。

## 構成（`faces/super-arbeiter/` の中）

```text
app.json                   Bip 6、appId、文字盤の場所（スマホの設定・Side Service はない）
watchface/index.js         通常表示、分ごとの更新、電池の塗り、画面が点いた時のセリフの切り替え
watchface/layout.js        座標・大きさ（四隅の丸みと端12pxを避ける）
watchface/theme.js         色・数字の画像の余白
watchface/quotes.js        セリフ7枚の並びと、次の札の選び方
watchface/glyphs.js        フォントで描く小さい文字（数字・「/」）と日本語の曜日の名前
watchface/glyph-widths.js  数字の画像の、字ごとの幅（generate-assets.mjs が書き出す。手で直さない）
watchface/digit-text.js    数字の画像を字ごとの幅で並べる（時刻・日付）
watchface/aod.js           AOD の表示
tools/prepare-source.mjs   受け取った素材を整えて source/ に保存する（1回だけ）
tools/generate-assets.mjs  source/ から、時計の画像（下の段のアイコンを描き込んだ背景・数字）とプレビューを作る
source/                    整えた素材（背景・セリフの札・小さい文字の字形）
assets/bip-6/images/       時計に入る画像
docs/                      README 用プレビュー
```

## 素材と権利

- 背景（暖簾のタイトル・提灯・丼・吹き出し・雷紋と、カレンダー・くつ・電池の枠のアイコン）とセリフの札7枚は、ユーザーから受け取った最終採用案の素材集（`super-arbeiter-final-pack.zip`、2026-09-30）に入っていた、この文字盤のために作られた絵です。暖簾のタイトルとセリフの文字は、ユーザーが用意したフォント（ちかフォント）で描かれたもので、フォントにない字は補助の書体で描かれています。
- `tools/prepare-source.mjs` で次のように整えて `source/` に入れています。
  - 背景：吹き出しの内側を、セリフの札と同じ平らなクリーム色にする。時刻の左のカレンダーと日付の下線、下の段のくつ・区切り・電池の枠は、まわりの黄色い地の模様で消す
  - アイコン（カレンダー・くつ・電池の枠）：背景から切り出し、黄色い地を透明にして `source/icons/` に保存する（`generate-assets.mjs` が下の段に並べ直す）
  - セリフの札：クリームの下地を透明にする（吹き出しの黒い枠を隠さないため。文字のふちは元の色のまま）
  - 小さい数字（日付・歩数・電池）：ちかフォント（ユーザー提供の `chika-Regular.ttf`、2026-09-30）で描いて `source/glyphs/` に保存する。少し太らせている
  - 時刻の数字（0〜9 と「:」）：M PLUS Rounded 1c Black（太い丸ゴシック。SIL Open Font License。Google Fonts の `ofl/mplusrounded1c/MPLUSRounded1c-Black.ttf`）で描いて `source/glyphs/time-*.png` に保存する。グッズのタイトルのような太い丸い字にするため（公式のフォントではない）
  - 使った書体は `source/glyphs/font.txt`
- 元の素材とフォントはリポジトリに入れていません（描いた字の画像だけを入れています）。作り直す時は、次のコマンドを実行します（`--chika` を省くと IPA ゴシックで描きます）。

```sh
node faces/super-arbeiter/tools/prepare-source.mjs <素材のフォルダ> --chika <chika-Regular.ttf> --time <MPLUSRounded1c-Black.ttf>
```

- 公式キャラクター・公式ロゴは使っていません。画面には、キャラクターの名前やセリフの出典を出しません。セリフを使うので、自分の時計で使うだけにし、ストアには出しません。
- AOD の日付と HP は、時計のシステムフォントで出します。

## 既知の制限

- 実機 Bip 6・Simulator では、まだ確認していません。ビルドまで確認済みです。特に次の点は実機で見る必要があります。
  - 通知アイコンが暖簾の上の赤い余白に収まるか（`layout.js` の `NOTIFICATION` は素材の見本から測った値）
  - AOD との切り替え、歩数・電池の数字と電池の塗りの更新
  - 画面が点くたびにセリフが替わるか（腕を上げた時・AOD から戻った時）
- `appId`（`20260930`）は仮の値です。自分の時計で使うだけならこのままでも動く見込みです。
- 12時間制にしている時、AM/PM は表示しません。
- 歩数は6桁（999999）まで区切りの手前に収まります。
- 日付・歩数・電池の数字の 0 と 4 は、ちかフォントでは横に広いので、枠に収まるように横だけ少し細くしています。
- 時刻は字ごとの幅で並べるので、数字が変わると時刻の幅が少し変わります（いつも画面の左右のまん中にそろいます）。
